Flip Monitors

Swap your left and right monitor with one click — handy when a laptop or second screen ends up on the other side of the desk. This one is a small Windows script you download and run, not a web tool.

What it does

⇄
  • Mirrors the monitor arrangement left-to-right, exactly as if you had dragged the screens around in Settings → System → Display.
  • Your main (primary) monitor stays the main monitor; only the positions change. Resolution, scaling and vertical alignment are left as they are.
  • The new layout is saved, so it stays after a restart. Run it again to flip back.
  • With more than two monitors, the whole row is mirrored around the main monitor.

Install

  1. Download both files and put them together in a folder that will stay put, for example Documents\Flip Monitors. The desktop shortcut points to this folder, so don't leave them in Downloads if you clean that up.
  2. Double-click add-flip-shortcut.cmd once. It adds a Flip Monitors shortcut with its own icon to your desktop. You can right-click it and pin it to the taskbar or Start.
  3. Click the shortcut whenever you want to swap the monitors. You can also just double-click flip-monitors.cmd directly — the shortcut is only for convenience.

If you move the folder later, run add-flip-shortcut.cmd again to update the shortcut.

If Windows warns you

Windows flags scripts downloaded from the internet. If you see "Windows protected your PC", click More info → Run anyway. You can avoid the prompt by right-clicking each file → Properties → tick Unblock → OK.

On managed work computers, IT may block scripts entirely. In that case, ask them — or flip the monitors by hand in Display settings.

How it works

Both files are plain text — open them in Notepad to read exactly what they do before running them.

  • flip-monitors.cmd starts PowerShell for this one script (no admin rights needed) and uses the standard Windows display API to read each monitor's position and write the mirrored one.
  • add-flip-shortcut.cmd saves the icon, which is embedded in the file, as flip-monitors.ico next to it and creates the desktop shortcut. Nothing is downloaded or installed.
  • If something goes wrong (for example, only one monitor is connected), the window stays open with a short explanation instead of closing.
